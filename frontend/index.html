参数类型默认状态说明
typestring— 已支持 按分类筛选，留空则从全部分类随机
pathstring— 已支持 固定图片相对路径，用于 /image 接口
formatstring— 已支持 限定图片格式：jpg / jpeg / png / gif / webp，可逗号组合；该格式下没有图片时返回 404
excludestring— 已支持 排除指定图片 ID，逗号分隔，最多 100 个
wint— 已支持 返回指定宽度的缩略图（160/320/480/640/960），带磁盘缓存；客户端支持时自动返回 WebP

常见问题

接口怎么用？

把 /random 当作图片地址用即可，例如 <img src="…/random">。

图片可以用在商业项目吗？

图片由本项目自行收集整理，版权归属原作者。商用前请自行确认授权，本项目不承担相关责任。

有调用频率限制吗？

为避免滥用，/random、/image、/thumb 按 IP 限流，默认每分钟 120 次，超限返回 429 并带 Retry-After。 请勿在循环中高频调用，图片请配合 w 参数取缩略图。

为什么每次打开图片都不一样？

/random 接口本身即随机，且响应头禁止缓存；如果需要固定图片，请使用 /image?path=… 直链。
